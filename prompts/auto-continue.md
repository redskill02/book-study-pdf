# 학습노트 자동 연속 작업 프롬프트

여러 권을 **묻지 않고** 끝까지 이어서 만들게 할 때, 새 세션 첫 메시지로 아래 블록을 붙여넣는다.
(에이전트의 권한 모드를 자동 허용으로 두면 중간에 멈추지 않는다.) `<…>` 는 자기 환경에 맞게 채운다.

책 학습노트를 대기열이 빌 때까지 자동으로 이어서 만들어라. 나에게 무엇을 할지 묻지 마라.
스킬: <SKILL 경로>/SKILL.md 와 references/ 를 그대로 따른다.

## 절대 규칙
1. 질문 금지. 판단이 필요하면 스킬의 규칙과 <진도표.md> 의 최근 §를 근거로 스스로 정하고, 정한 근거를 진도표에 한 줄 남긴다.
2. 한 권이 끝나기 전에는 멈추지 않는다. 한 권이 끝나면 보고 없이 곧바로 다음 권을 시작한다. 보고는 각 권의 진도표 §로 대신한다.
3. 컨텍스트가 요약되어도 이 프롬프트의 규칙은 유지된다. 요약 뒤 첫 행동은 반드시 "3. 재개 절차"다.
4. 셸 명령에 `$var` 확장을 쓰지 않는다(권한 프롬프트가 뜬다). 반복 실행은 파이썬 스크립트(`checkall.py` 등)로 한다.
5. 원본 PDF · 완성본을 절대 지우거나 덮어쓰지 않는다. 작업 폴더 이름은 새로 만들기 전에 `ls <작업 루트>/` 로 중복을 확인한다.
6. 긴 작업(MinerU · rotate · downsample)을 기다릴 때 턴을 끝내지 않는다. `until [조건]; do sleep 20; done` 을 10분 단위로 반복 실행해 붙잡고 있는다.

## 1. 대기열 (이 순서대로, 완료된 것은 건너뛴다)
완료 판정 = `<배포 루트>/<책이름>/` 안에 `*_전권합본.pdf` 가 실제로 있고 진도표에 완료 §가 있는 것.
A. <폴더 A> — <책 목록 또는 "파일명 순">
B. <폴더 B> — …
주식·차트 도서는 스킬의 chart 규칙(실제 차트는 원본 크롭 + 한글 주석, UI 캡처·개념도는 재작도), 나머지는 redraw. 영어 원서는 translate.

## 2. 한 권의 순서 (건너뛰기 금지)
0. 스캔본 완전성: 차례 마지막 쪽번호 vs 마지막 권 끝 쪽. 빠진 범위는 표지·1권·마지막 권에 명시.
0. `probe.py _src` → 재OCR 판정. 0.5 `rotate.py scan/fix` (MinerU venv 파이썬으로, 백그라운드).
1. MinerU `-b pipeline -m ocr -l korean` (영어 원서는 `-l` 생략). 여러 권이면 전부 끝날 때까지 집필 금지.
   chart 책은 이중 트랙: 300dpi 사본으로 구조화 → 원본으로 `image·table·chart` 전부 크롭.
2. `split.py` 분할 → 3. 컨택트시트 전수 확인 → `_GATE.md` 에 도판 분류와 권 구성표를 쓴다.
4. 집필: 권마다 만화 2 · 예시 3 · 시험 30~36문항 · 덮고쓰기 → 시험 → 합격선 → 튜터 순서. 크롭은 반드시 `idsheet.py` 로 눈으로 확인한 뒤 캡션을 쓴다.
5. 권마다: `_fix.py` → `_chain.py NN --nobuild` → `prewidth.py 100` → `_chain.py NN` → `_rep.txt` 가 빌 때까지 → `_ovNN.png` · 만화 100% · 도표 쪽 5장 이상 눈으로 → `_done.py NN "…"`.
6. 전권 끝: `_front.html`(차례 · 1-4-7-14 학습계획표 · 사용법 · 서지/개인학습용 문구) + `ch99.html`(지도 · 용어집 · 숫자 · 체크리스트 · 종합시험 · 만화 2 · 예시 3).
7. `audit.py <out폴더> .` 정방향 + `audit_kw` 역방향 → 오탐/실제 누락을 가르고 누락은 보완.
8. `build.py all` → `merge` → `imgcheck.py all` → `deploy` → 배포 폴더의 합본 1 + 권별 PDF 수를 센다.
9. 기록: 진도표 §N(수치표 · 권 구성 · 새로 배운 것 · 감사 결과), 새 함정은 스킬 `references/pitfalls.md` 에 번호 붙여 추가.
10. 다음 권으로.

## 3. 재개 절차 (세션 시작 · 컨텍스트 요약 직후 반드시)
1. `ls -lt <작업 루트>/ | head` — 가장 최근 `book_*` 폴더를 연다.
2. 그 폴더의 `book.json`, `ls -lt ch*.html`, `_stats.txt`, `_GATE.md` 로 어느 단계인지 판단한다. 진도표는 참고만 한다(어긋난 적 있음).
3. `_chNN_b.html` 같은 부분 파일이 있으면 본문에 합쳐졌는지 `build.py blocks` 로 확인하고 합친다.
4. 멈춘 단계부터 이어서 한다. 처음부터 다시 하지 않는다.

## 4. 판단 기준 (묻지 말고 이렇게)
- 모드: 한국어 책 = digest, 영어 원서 = translate. 도판: 저자의 매매 흔적이 인쇄된 실제 차트가 있으면 chart, 아니면 redraw.
- 권 나누기: 한 권 18~31쪽, 원서 장 경계를 살리되 절 2~5개씩 묶는다.
- probe 가 "재OCR 필수"면 재OCR 후 `--compare` 확인, 개선 없으면 원본 레이어를 두 번째 눈으로 쓴다.
- rotate `보류` 는 `peek` 으로 직접 보고 정한다.
- 판권면에 AI 사용 금지 문구가 있으면 `_front` 서지에 "개인 학습용, 배포하지 않음"을 명시하고 계속한다.
- 검사기가 0건 통과를 내면 검사기 고장을 먼저 의심한다.
- 어떤 문제로 한 권이 막히면 그 권을 진도표에 "보류: 이유"로 적고 다음 권으로 넘어간다. 대기열 전체를 멈추지 않는다.
