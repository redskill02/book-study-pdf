# 책 유형 판별 — 무엇을 재작도하고, 무엇을 크롭하고, 무엇을 번역하는가

집필을 시작하기 전에 **딱 두 가지**를 정한다. 둘 다 `book.json` 에 적는다.

```json
{ "mode": "translate | digest",  "figures": "redraw | chart" }
```

나머지 세부 유형(코드 책 · 에세이 · 인터뷰 · 원칙서)은 위 두 값 안에서 **집필 요령만** 달라진다. 규칙 · 순서 · 검사기는 전부 같다.

---

## 1. 언어 축 — `mode`

| 판별 | 값 | 근거 |
|---|---|---|
| 본문이 영어(또는 다른 외국어) | `translate` | 한국어로 번역하며 정리 · 사례를 한국 맥락으로 대체 → `translate-mode.md` |
| 본문이 한국어 (국내서 · **한국어 번역서**) | `digest` | 번역 불필요. 더 쉬운 말로 재정리 · 예시 추가 → `writing.md` "digest" |

**판별 절차**
1. `probe.py` 결과(`_probe.txt`)의 **한글 글자 비율**을 본다 — 한글이 본문의 절반 이상이면 `digest`.
2. 텍스트 레이어가 없으면 첫 본문 3쪽을 `rotate.py peek` 으로 뽑아 눈으로 본다.
3. 영어 원서인데 **한국어 번역본 PDF 도 함께 있으면 한국어본으로 `digest`** 한다 — 번역 품질보다 검증 가능성이 중요하다(원문 대조가 같은 언어끼리라 훨씬 정확하다).
4. 애매하면(이중언어 · 일본어 등) `translate` 로 두고 첫 권 집필 전에 원문 5쪽을 번역해 보고 결정한다. **묻지 않는다.**

**번역서(`digest`)의 추가 규칙** — 인명 · 용어는 **표준 음역이 아니라 그 책의 표기**를 따른다(케인즈 · 후르시초프 · 코카서스). 역방향 대조(`audit_kw`)가 책의 표기로 검사하기 때문이고, 학습자가 책을 펼쳤을 때 같은 말이어야 한다(함정 #35 · #101).

MinerU 언어 플래그는 `digest` → `-l korean`, `translate` → 생략(기본값).

## 2. 도판 축 — `figures`

| 판별 | 값 | 도판 처리 |
|---|---|---|
| 도판이 **개념도 · 표 · 순서도 · 삽화 · 캡처** | `redraw` | 전부 **한글 인라인 SVG 재작도**. 원본 이미지를 지면에 넣지 않는다 |
| 도판에 **저자의 매매 흔적이 인쇄된 실제 차트 · 기록표**가 있다 | `chart` | **5분류** — C(실제 차트) · D(사진)는 **원본 크롭 + 한글 주석**, A · B · D′(개념도 · 패턴 도해 · UI 캡처)는 재작도, E(장식)는 버림 → `chart-mode.md` |

**`chart` 판정 기준은 "차트처럼 생겼는가"가 아니다.** 기준은 하나 —
**"저자가 사고판 자리(Ⓐ~Ⓖ · A·B·C · 화살표), 실제 종목 · 기간, 실제 거래 기록이 도판에 인쇄되어 있고 본문이 그 기호로 서술하는가."**
그렇다면 다시 그리는 순간 "교과서 속 깔끔한 패턴"이 되어 **실제 차트의 지저분함을 읽는 기술**이라는 학습 목표가 사라진다.

| 도판 | 판정 | 왜 |
|---|---|---|
| 특정 종목 · 기간의 주가 차트에 매수 · 매도 표시 | **C 크롭** | 실물이 증거이자 훈련 자료 |
| 저자의 매매 일지 · 전면 기록표 | **C 크롭 (전면)** | bbox 가 캡션을 자른다 — 전면 크롭 |
| 캔들을 지우고 이평선만 남긴 손 도해 | A 재작도 | 개념도다 |
| 헤드앤숄더 · 갭 · 정배열 같은 이상화 패턴 | B 재작도 | 원본이 이미 도식이라 재작도가 더 깨끗하다 |
| HTS · MTS 설정 화면 (534×847 · 40~80KB) | **D′ 재작도**(한글 화면 목업) | 크롭하면 글자가 안 읽힌다. 수식이 적힌 화면은 특히 |
| matplotlib 등 코드가 만든 차트 | C 크롭 | 코드 책(`digest`)에도 나온다 — `figures: chart` 로 |
| 한국어판이 차트 라벨을 이미 한글로 다시 인쇄한 책 | C 크롭만 | 재작도할 이유가 없다. 개념도만 재작도 |
| 같은 차트가 두 번 실림(앞은 상승만, 뒤는 하락까지) | 둘 다 크롭 | 나란히 놓는 것 자체가 논증 |
| 지도 · 인구 그래프 (지정학서) | C 크롭 | 데이터가 정보다. 개념도는 재작도 |
| 인물 사진 · 아이콘 · 부속 표지 · 빈 말풍선 | E 버림 | |

`chart` 책이라도 **크롭 0장이 나올 수 있다** (UI 캡처만 있는 코딩 따라하기 책 → 전부 재작도). 반대로 `redraw` 책에서 데이터 그래프가 나오면 그 도판만 C 로 다루고 `figures` 를 `chart` 로 바꾼다 — 검사기 4종(`imgcheck.py`)이 켜져야 하기 때문이다.

## 3. 세부 유형별 집필 요령 (두 축 안에서)

| 세부 유형 | 특징 | 요령 |
|---|---|---|
| **경영 · 마케팅 · 자기계발** | 프레임워크 · 단계 · 체크리스트 | 그림에만 있는 프레임워크를 찾아라. 줄글로 뭉친 "N가지"를 표 · 도표로 |
| **원칙서 · 심리서** | 규칙과 실험 | 쉬운 예시는 "책의 규칙 → 독자의 서식"으로(함정 #89). 효과 이름 + 수치는 역방향 대조 대상 |
| **코드 책** | 코드 블록 · 실행 화면 | 코드를 `<pre>` 로 옮기지 말고 **핵심 줄 표**로 요약, **변수 추적표(K 예시)** 로 이해 확인. 실행 화면은 절차 표. 장별 퀴즈는 시험 Q1~5 로, 정답 대조표는 부록 권에 |
| **에세이 · 회고** | 서사 · 인용 | 권마다 도표를 '대비 · 인용 열두 줄 · 숫자 · 사람 · 한 줄과 다음' 고정 형식으로 |
| **인터뷰집 · 사례집** | 인물마다 반복 구조 | 각 권 도표를 'N권의 인용 · 숫자 · 한 줄 · 다음' 고정 형식 → 총정리에서 `re` 로 뽑아 조립. 4.3pt 줄은 처음부터 ≤80자 |
| **주식 · 차트 (국내 단타 · HTS)** | 크롭 100장 이상 | 크롭 밀도 권당 5~8장. 900px 미만 작은 크롭은 PIL 몽타주 6~8장 + 한글 라벨로 한 도표 |
| **주식 · 차트 (번역서 · 미국 차트)** | IBD · 캔들 | 티커 · 종목명 캡션은 `idsheet.py` 로 눈으로 확정 후에만 |
| **가치투자 고전 (재무표 많음)** | 표 161장 | 표는 전부 SVG 표 재작도(셀마다 `<text>`), 차트만 크롭 |
| **지정학 · 데이터 책** | 지도 · 인구 그래프 | 지도 · 그래프는 크롭, 개념도는 재작도. 분권 오프셋 권마다 |
| **부록 · Q&A 가 있는 책** | 실행 규칙이 부록에 | **부록은 반드시 별도 권**으로. 본문과 교차 대조하면 본문의 빈칸이 메워진다 |

## 4. 판별 결과를 어디에 적나

`_GATE.md` 첫 절에 한 줄 —

```
- 판정: digest · chart (실제 종목 차트 54장 = table 21 / image 22 / chart 11 · UI 캡처 19장은 재작도) · 책 = pdf − 1
```

이 한 줄이 이후 모든 권의 캡션 형식(`원본 N권 M쪽`) · 검사기 세트(8종 vs 12종) · 추출 도구(`_extm` vs `_extf`) 를 결정한다.
