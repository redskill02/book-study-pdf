# 영어 원서 — 한국어 번역 정리 모드 (`mode: translate`)

영어(외국어) 원서를 **한국어 학습노트**로 만든다. 번역기가 아니라 **번역하며 정리하는** 작업이다.
`$100M Offers · Leads · Money Models · Lost Chapters`(Alex Hormozi) 4권으로 확립했고, 스킬 없이 만든 첫 권은 누락 10건, 스킬로 만든 두 권은 0건이었다.

`digest` 와 다른 것은 **본문 정리 · 예시 · 대조 방법** 셋뿐이다. 도표 · 만화 · 덮고 쓰기 · 시험 · 합격선 · 튜터 · 검사기 12종은 전부 같다.

---

## 1. 출력 언어 규칙

| 대상 | 규칙 | 예 |
|---|---|---|
| 본문 · 요약 · 설명 · 시험 · 해설 · 만화 대사 · 캡션 | **전부 한국어** | |
| 핵심 용어 (프레임워크 · 고유 개념) | **한국어 + 괄호 원어**, 그 권에서 **처음 나올 때** 한 번. 이후는 한국어만 | 가치 방정식(Value Equation) · 그랜드 슬램 오퍼(Grand Slam Offer) · 리드 마그넷(Lead Magnet) |
| 원서 고유 표현 · 슬로건 | 한국어 번역 뒤 **원문 인용**을 `<span class="quote">` 로 살린다. 매끄럽게 다듬다가 힘을 잃는 문장이 있다 | "사람들은 상품을 사는 게 아니라 결과를 산다" *(They don't buy products, they buy outcomes)* |
| 인명 | 외래어 표기법에 가깝게 + 첫 등장 시 원어 | 알렉스 호르모지(Alex Hormozi) |
| 회사 · 제품 · 브랜드 | 원어 그대로 (널리 쓰이는 한글 표기가 있으면 그것) | Gym Launch · 스타벅스 |
| 숫자 · 화폐 | 원문 수치 유지 + 필요하면 괄호로 원화 어림(환율 명시) | $10,000(약 1,300만 원, 1달러=1,300원 기준) |
| 단위 | 미터법으로 환산하되 원문 병기 | 10마일(약 16km) |
| 약어 | 첫 등장에 풀어쓰기 | LTGP(고객 생애 총이익, Lifetime Gross Profit) · CAC(고객 획득 비용) |
| 장 · 절 제목 | 한국어 의역 + 원제 병기(목차 · 커버 `.sec` 에) | SECTION III — 리드 얻기(Get Leads) |
| 책 제목 | 한국어판이 있으면 한국어판 제목, 없으면 원제 그대로 | 『$100M Offers』 |

**하지 말 것**
- 직역투("~하는 것은 ~이다")를 그대로 두지 않는다. 한 문장에 주장 하나, 짧게.
- 용어를 매 문단마다 병기하지 않는다. 읽기가 끊긴다.
- 원문에 없는 주장을 만들지 않는다. 쉽게 푸는 것과 내용을 바꾸는 것은 다르다. 저자의 결론은 그대로.

## 2. 본문 정리 — 원문 구조를 유지한다

- 원문의 **헤딩 · 목록 · 표 구조를 유지**하며 옮긴다. `digest` 처럼 구조를 새로 짜지 않는다 — 원문 대조가 구조 단위로 이뤄지기 때문이다.
- 원문 h4 이하의 하위 절이 **"N가지 방법"** 형태면, **N개 항목 각각의 본문**을 옮긴다. 표 한 장으로 요약하고 넘어가면 그 안의 사례 · 수치 · 프로세스가 통째로 사라진다(『$100M Leads』 "가치를 더 주는 6가지"가 표만 있고 본문이 비어 있었다).
- **저자의 일화 · 실패담**은 줄이지 않는다. 그것이 만화의 재료다.
- 원서의 **Pro Tip · 사이드바 · 각주**도 옮긴다(`.note`). 원문에서 눈에 덜 띄는 위치일수록 핵심 조건이 숨어 있다.
- 영어 원서에도 **그림에만 있는 개념**이 있다(Splinter Stack · Delivery Cube 6축 중 절반). 컨택트시트를 전수 확인한다.

## 3. 예시 — 미국 사례를 한국 사례로 대체한다

원문 사례가 미국 맥락(체육관 프랜차이즈, 달러 금액, 미식축구)이면 **한국 독자용 예시를 새로 만든다.**
원문 예시를 **지우지 말고** 그 옆(또는 앞)에 짧게 두어 대조가 가능하게 한다.

```html
<div class="kr-case">
<span class="tag">한국 사례 1</span>
<h4>LTGP:CAC 를 자기 숫자로 — 필라테스 스튜디오</h4>
<p>원문: 짐 런치(Gym Launch)가 회원 1명당 … (원서 p143). 한국 상황으로 바꾸면 —</p>
<pre>월 회비 22만 원 × 평균 8개월 유지 = 176만 원   (LTV)
원가율 30%  → 생애 총이익 LTGP = 123만 원
광고비 60만 원 / 신규 6명 → CAC = 10만 원        → LTGP:CAC = 12:1 (기준 3:1)</pre>
<div class="cmp">원문과 같은 점 — 3:1 기준 · 총이익으로 계산. 다른 점 — 한국은 카드 수수료 · 부가세를 총이익에서 뺀다.</div>
</div>
```

- 업종은 한국에서 흔한 것으로: 필라테스, 학원, 배달, 미용실, 카페, 병원, 온라인 쇼핑몰.
- **숫자를 넣는다.** 원문 프레임워크에 실제 값을 대입해 계산 과정을 보여준다. 환율 · 세금처럼 미국과 다른 조건은 `.cmp` 에 밝힌다.
- 원문 개념과 **어디가 같고 어디가 다른지** 한 줄로.
- 권당 예시 3개. 하나는 반드시 **숫자 계산**, 하나는 **의사결정 상황**.

## 4. 만화 · 도표 · 시험 — 언어만 다르다

- **만화** — 저자의 일화(호르모지의 짐 런치 붕괴 · 첫 오퍼 실패)를 4컷으로. 말풍선은 한국어. 고유명사는 원어 유지.
- **도표** — 원문 도표를 **한글 라벨로 재작도**한다. 원문 라벨은 캡션에 병기(`원문 p158~163 "Value Equation" 을 한국어로 재작도`). `chart` 책이면 실제 차트는 크롭하고 주석만 한국어(`chart-mode.md`).
- **시험** — 한국어. 단, **용어를 묻는 단답 문항은 원어로 답해도 정답**임을 해설에 적는다. 설명형 1문항 필수.
- **튜터 프롬프트** — 한국어. 책 원제와 장 번호를 박아 둔다.

## 5. 원문 대조 — 단어 매칭이 안 된다 (`audit.py --mode translate`)

원문 영어 / 노트 한국어라 자동 매칭이 성립하지 않는다. `audit.py` 는 판정하지 않고 **사람이 볼 체크리스트**를 만든다.

```bash
python audit.py "<MinerU md 폴더>" . --mode translate     # 또는 book.json 의 mode
cat _audit.txt
```

`_audit.txt` 에 나오는 것 —
1. **[A] 원문 헤딩 전수 목록** `[ ]` — 하나씩 노트에서 찾아 체크한다. 자동 체크 없음.
2. **[B] 열거형 표현** (`6 ways` · `3 steps` · `N가지`) — **N개 항목이 각각 본문을 갖는지** 센다. 표만 있고 내용이 없으면 누락이다.
3. **[C] 앵커** — 원문에 3회 이상 나오는 고유명사 · 대문자 약어 · 수치가 노트에 없으면 표시. `PS` / `P.S.` 처럼 표기 변형을 함께 본다(함정 #12b).

**키워드는 반드시 원문에서 뽑는다.** 사전 계획서로 뽑으면 원문에 없는 개념(파랑새 우화 · PS문)을 찾느라 시간을 버린다. 없다고 결론 내리기 전에 `grep "^#"` 로 헤딩 목록을 눈으로 훑는다.

**역방향 대조(`audit_kw_template.py`)** — 노트가 "원문에 있다"고 주장한 **효과 이름 · 수치 · 원어 병기 용어**를 CLAIMS 로 넣어 원문 md 에서 찾는다. 원어 병기가 있으므로 `translate` 에서 역방향 대조는 오히려 정확하다. 객관식 **오답 보기의 수치는 넣지 않는다**(원문에 없는 것이 정상).

**심각도** — 🔴 프레임워크(WHAT·WHO·WHEN, 속삭임→놀림→외침) > 🟡 프로세스 · 의사결정 도구 > 🟢 사례 · 팁. 이 순서로 채운다.

## 6. MinerU · 텍스트 레이어

- MinerU 는 `-l` 을 생략(기본값). 영어 OCR 은 원본 텍스트 레이어와 정확도가 비슷하니, `probe.py` 가 양호하면 텍스트 레이어(`srcpdf.py`)를 두 번째 눈으로 쓴다.
- 영어 원서의 흔한 OCR 오류 — `rn`↔`m`, `l`↔`1`, 하이픈 줄바꿈(`in-\nvestment`). 수치는 문맥으로 검산한다.
- 파일명만 보고 판단하지 않는다 — `LOST MONEY MODELS` 라고 적힌 파일이 본편 `Money Models` 였다. **표지를 읽는다.**

## 7. 학습 순서가 있는 시리즈

시리즈물은 **출간 순서 = 개념 의존 순서**인 경우가 많다(Offers → Leads → Money Models → Lost Chapters). `_front.html` "이 학습노트에 대하여"에 **시리즈 안에서의 위치**와 선행 권을 적는다. 뒤 권의 튜터 프롬프트에는 앞 권 개념 이름을 원어와 함께 박아 둔다.
